# Well Log Data Analyser

A Python-based petroleum data analysis project designed to explore, clean, analyse, visualise, and extract insights from well and production data.

This project brings together practical Python, Pandas, data cleaning, statistical analysis, visualisation, profitability analysis, well clustering, and automated reporting into a single petroleum-focused data science portfolio.


## Project Overview

The goal of this project is to demonstrate how Python and data science techniques can be applied to petroleum and well-production data.

The project focuses on transforming raw or structured well data into meaningful information that can support:

- Production analysis
- Well performance evaluation
- Data quality assessment
- Field and operator comparisons
- Profitability analysis
- Well clustering
- Production visualisation
- Automated reporting
- Petroleum data-driven decision support


## Technologies Used

- **Python**
- **Pandas** - data manipulation and analysis
- **NumPy** - numerical computations
- **Matplotlib** - data visualisation
- **Scikit-learn** - machine learning and clustering
- **SQL** - relational petroleum data analysis
- **CSV** - structured data storage and exchange


## Project Structure

The repository contains several Python programs, datasets, analyses, and visual outputs.

### Data Analysis

| File | Description |
|---|---|
| `data_cleaning_pipeline.py` | Cleans and prepares well/production data for analysis |
| `data_visualisation_analysis.py` | Generates visual analyses from the dataset |
| `well_production_analysis_sample.py` | Performs well production analysis |
| `well_intelligence_analysis.py` | Produces broader well/field intelligence |
| `field_intelligence_system.py` | Combines multiple analytical processes into a field intelligence workflow |

### Advanced Analysis

| File | Description |
|---|---|
| `advanced_groupby_profitability.py` | Performs grouped profitability and performance analysis |
| `well_clustering_analysis.py` | Applies clustering techniques to identify groups of wells |
| `automated_report_generator.py` | Generates analytical reports from processed data |

### Supporting Files

The repository also contains datasets, generated charts, reports, and other supporting files used by the analysis programs.
